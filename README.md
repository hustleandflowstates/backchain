# backchain
Backward-chaining memorization coach for Claude. A hands-free, chat-based rehearsal loop that builds a passage from its final segment backward, with intention-framed navigation and non-punitive accuracy tracking. Applies to scripture, verse, monologue, song lyrics, speeches, oaths, technical recitation, or any text that must be reproduced verbatim from memory.

The method: learn the **last** segment first, then the second-to-last plus the last, and so on — always reciting *toward* ground already known. Forward rehearsal front-loads the opening and starves the finish; backward chaining inverts that so every run gains confidence as it proceeds and terminates on the strongest material.

Trigger with `/backchain` or `backchain`, or by pasting a passage and asking to commit it to memory.
